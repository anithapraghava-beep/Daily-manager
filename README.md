# Daily Manager Web App

A simple web app to manage daily tasks, timetables, and reminders.

## Features
- ✅ To-do list with completion tracking
- 📅 Daily timetable scheduling
- 🔔 Reminders with browser notifications
- 📱 Mobile-responsive design
- 💾 Data saved locally in browser

## How to Use on Phone

### Method 1: GitHub Pages (Recommended)
1. Create a GitHub repository
2. Upload these files
3. Enable GitHub Pages in repository settings
4. Access via the provided URL on your phone

### Method 2: Local File
1. Transfer files to your phone
2. Open `index.html` in your phone browser

### Method 3: Free Hosting
Upload to services like:
- Netlify (drag & drop)
- Vercel
- GitHub Pages

## Browser Permissions
The app will request notification permission for reminders - make sure to allow it for the best experience.
